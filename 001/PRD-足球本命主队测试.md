# 1 产品概述

## 1.1 产品名称

**「足球本命主队测试」** — Find Your Football Soul Club

## 1.2 项目背景

足球是全球第一大运动，五大联赛+全球各级别联赛拥有超过200+职业俱乐部。大量"泛球迷"在选择主队时缺乏系统认知，往往因某球星、某场比赛偶然入坑。本项目通过**50道趣味测试题**，从用户性格、审美偏好、足球理解、价值观等维度，科学匹配最适合用户的"本命足球俱乐部"，降低选队门槛，增强归属感与传播性。

## 1.3 目标用户

| 用户画像 | 特征描述 | 核心诉求 |
|---------|---------|---------|
| 足球小白 | 刚接触足球，想找一支主队长期关注 | "我不知道喜欢谁" |
| 泛球迷 | 看球但无固定主队，多个联赛随意看 | "给我一个坚定的理由" |
| 社交传播型 | 朋友圈/小红书/抖音爱分享测试结果 | "晒我的本命球队" |
| 硬核球迷 | 已有主队，想验证/娱乐 | "看看测得准不准" |

## 1.4 产品定位

**轻量化H5纯前端静态网页** — 足球主题人格测试工具。类比"MBTI人格测试"+"哈利波特分院帽"的足球版。无服务端、无数据库、无登录注册，即开即测，结果可截图分享。

## 1.5 核心价值

| 维度 | 说明 |
|-----|------|
| 娱乐性 | 50道趣味题 ≈ 3分钟完成，节奏轻松不枯燥 |
| 科学感 | 多维度评分算法匹配，非随机抽签，让用户觉得"有道理" |
| 传播力 | 结果页精美海报感，天然适合社交分享截图 |
| 零门槛 | 扫码/点击即用，无需下载App/注册账号 |

# 4 核心数据逻辑

## 4.1 题库数据结构

每题为一个对象，存储在 `questions` 数组中：

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `id` | number | ✅ | 题目序号，1-50 | `1` |
| `question` | string | ✅ | 题干文字，≤30字 | `"你更看重一支球队的什么？"` |
| `options` | array[4] | ✅ | 4个选项，每个{text, scores} | 见下方 |
| `options[i].text` | string | ✅ | 选项文字，≤15字 | `"豪门底蕴与荣誉"` |
| `options[i].scores` | object | ✅ | 各俱乐部得分映射 `{clubKey: score}` | `{"real_madrid": 3, "barcelona": 2}` |
| `category` | string | ✅ | 题目维度分类 | `"价值观"` |

**题目维度分类（6个维度，覆盖50题）：**

| 维度 | 题量 | 说明 |
|-----|------|------|
| 价值观 | 10题 | 进攻vs防守、美丽vs实用、传统vs革新 |
| 审美偏好 | 8题 | 球衣颜色、队徽风格、球场氛围 |
| 性格匹配 | 10题 | 激进vs稳健、忠诚vs变通、个人vs团队 |
| 足球理解 | 8题 | 战术偏好、球员类型偏好 |
| 生活方式 | 7题 | 看球时间、社交习惯、消费观念 |
| 情感倾向 | 7题 | 逆袭偏好、地域认同、历史情怀 |

## 4.2 结果匹配计分算法规则

**算法类型：累积加权评分匹配（Accumulated Weighted Score Matching）**

```
1. 初始化：所有俱乐部 score = 0
2. 遍历用户50道题的选择：
   → 每题选中的选项包含 scores 映射 {clubKey: 该题得分}
   → 将各 clubKey 的得分累加到对应俱乐部总分
3. 维度加权（可选，V1简化）：
   → 6个维度等权重，直接累加
4. 排序：所有俱乐部分数从高到低排列
5. 输出：
   → TOP1 = 本命主队（匹配度 = 该队得分/该队理论满分 × 100%）
   → TOP2~4 = "你也可能适合"推荐列表
```

## 4.3 兜底兼容策略

| 场景 | 策略 |
|-----|------|
| 最高分并列(≥2支) | 比较"价值观"维度分→"审美偏好"维度分→"性格匹配"维度分，优先级递减，仍并列则随机选1支 |
| 用户中途退出(未答完50题) | `localStorage` 暂存已答题目和进度，下次打开弹窗"是否继续上次测试？"，确认则跳转至中断题号 |
| 浏览器不支持 localStorage | 无暂存功能，退出即丢失，静默降级不弹错误提示 |
| 用户秒选/异常快速(每题<0.3s) | 不拦截，正常计分（不预设"防刷"，保持娱乐性） |
| Web Share API 不可用 | 降级为"长按截图保存"引导文案 |
| JS 加载失败 | `<noscript>` 标签显示"请启用JavaScript以进行测试" |
| 旧浏览器不支持 backdrop-filter | 卡片背景降级为 `rgba(255,255,255,0.12)` 不加模糊，功能不受影响 |

## 5.2 页面性能指标

| 指标 | 目标值 | 测量方式 |
|-----|--------|---------|
| 首屏加载(LCP) | < 1.5s | 纯静态，无外部依赖 |
| 页面切换响应 | < 100ms | CSS过渡，无JS阻塞 |
| 总资源大小 | < 80KB | HTML+CSS+JS gzip后 |
| 动画帧率 | ≥ 60fps | CSS transform/opacity 仅触发 composite |
| 无外部请求 | 0 | 所有资源内联或本地，无CDN/API调用 |

## 5.3 资源规范

| 项目 | 规范 |
|-----|------|
| 图标/队徽 | 使用 emoji + CSS 绘制，不使用图片（避免HTTP请求） |
| 字体 | 系统默认字体栈，不引入Web Font |
| 外部依赖 | **零外部依赖** — 无jQuery、无框架、无CDN引用 |
| 文件结构 | `index.html` + `style.css` + `script.js` 三文件，同目录 |

## 5.4 项目约束

| 约束项 | 说明 |
|--------|------|
| **无服务端** | 纯前端静态页面，可直接双击HTML在浏览器运行 |

| **无用户系统** | 无登录/注册/用户ID |
